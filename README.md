# 新加坡周末出门地图（独立版）

一页网页地图：从新加坡 Tanjong Pagar 站出发，周末能去的景点、美食、周边国家短途与 8 条路线，打开 `index.html` 就能用，不用装任何东西。

- 数据读取日期：2026-10-11。价格、开放时间与出入境规则会变，出门前以官网为准。
- 地图署名：底图 Tiles © Esri; Sources: Esri, HERE, Garmin, USGS, NGA, OpenStreetMap contributors（瓦片来自 server.arcgisonline.com 的 World Street Map）。
- 地图程序：页面里内嵌了 Leaflet 1.9.4（https://leafletjs.com），取自 npm 官方包 leaflet-1.9.4.tgz（sha512-nxS1ynzJOmOlHp+iL3FyWqK89GtNL8U8rvlMOsQdTTssxZwCXh8N2NB3GDQOL+YR3XnWyZAxwQixURb+FA74PA==），按 BSD 2-Clause 许可再分发；版权声明与许可全文保留在页面里 Leaflet 代码前的注释中（Copyright (c) 2010-2023, Volodymyr Agafonkin; Copyright (c) 2010-2011, CloudMade）。
- 断网或底图连不上时：只缺底图，列表、搜索、筛选、详情与路线连线照常可用。
- `data.json` 是页面里同一份数据的单独文件，方便查看；页面本身不读它。
